**🛠️ What I build**

- **[my-cloud](https://github.com/LF2Zetrei/my-cloud)** — a minimal cloud provider written from scratch in Rust, with no web framework, no async runtime and no Docker: a reverse proxy with token auth, a container orchestrator with a reconciliation loop (OverlayFS + cgroups), an S3-style object store, `/proc`-based metrics, a ChaCha20-Poly1305 VPN tunnel and a Next.js dashboard.
- **[infra-bylucas](https://github.com/LF2Zetrei/infra-bylucas)** — the infrastructure behind `bylucas.eu`, fully as code: Terraform for OVH DNS, Ansible for the VPS (hardening, fail2ban, Nginx + Let's Encrypt, PostgreSQL, Docker, one systemd service and vhost per project, secrets in Ansible Vault). Adding a project takes a few lines of configuration.
- **[infra-github-actions](https://github.com/LF2Zetrei/infra-github-actions)** — one reusable GitHub Actions workflow that builds and deploys Node, Python, Rust, Spring Boot and static projects to the VPS.
- **[monitoring](https://github.com/LF2Zetrei/monitoring)** — a private dashboard for the VPS: service status, memory, live logs over Server-Sent Events, restarts and certificate re-issuance, with an allow-list and a scoped sudoers file.
